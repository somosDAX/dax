## ¿Qué es DAX?

**DAX** nació en **2026** con una idea muy clara, sólida y ambiciosa: simplificar el desarrollo web y transformarlo en experiencias interactivas, profesionales y de alto rendimiento. 

Más allá de una marca, nuestro nombre representa la sinergia, el esfuerzo y el ADN de las tres mentes que impulsan este motor:

* **D**avid
* **A**drian 
* **X**abier 

Tres perfiles diferentes, una única identidad. Por eso somos **DAX**.
